================================================================================
INSTALLATION TROUBLESHOOTING
================================================================================

Problem: "pip3: command not found"
Solution: pip3 is missing. Install Python 3 with pip:
  macOS: brew install python3
  Ubuntu: sudo apt-get install python3-pip
  Windows: Download from python.org

Problem: "ModuleNotFoundError: No module named 'cryptography'"
Solution: Install dependencies:
  pip3 install -r requirements.txt

Problem: "ModuleNotFoundError: No module named 'tkinter'"
Solution: Tkinter is part of Python. Reinstall if needed:
  macOS: brew install python-tk
  Ubuntu: sudo apt-get install python3-tk
  Windows: Tkinter included with Python installer

Problem: GUI doesn't appear
Solution: Check X11/display:
  echo $DISPLAY  # Should show something like :0
  Or try: python3 -m main

Problem: "Permission denied" on test file
Solution: Make directory writable:
  chmod u+w .
  python3 test_encryption_system.py
